# Evidence

Files written by the app's **Save as evidence** buttons (Tasks and runs → a run; Approval Centre → Audit log), one per demonstration or test, plus screenshots added by hand.

Every file is generated from what the app recorded (plan, timeline, task outputs, models, approvals, audit log) and says whether its outputs are **LIVE** (real models and tools) or **SIMULATED** (the mock model). See `docs/DEMOS.md` for how each was produced.
